# Data Science Interview Sandbox

This repository contains data and code to use during a data science interview. This repository is specifically for the candidate, so it should only contain data that the candidate can see, and crucially should not contain answers.

## Robot Subscription Default Analysis

In this technical task, we'd like you to analyse the data in the `robot_subscription_data` folder. It contains information about a robot subscription company: a company that rents out robots to commercial and individual customers for various purposed including cleaning and warehouse operations.

We would like to predict: *what makes customers default on their subscription payments?*

For your analysis, we'd like you to write pseudo-code to show your thinking and data science skills. Please focus on:
- exploratory data analysis
- feature engineering
- proposals for model building

You do not have to produce working code, but we would like you to demonstrate your analytical thinking, coding structure and use of data science methods.
